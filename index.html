Hermes Workspace

個人用の AI アシスタント(Hermes)から、開発者自身の Gmail と Google カレンダーを操作するための、個人開発の連携ツールです。

概要

開発者本人のアカウントだけを対象に、メールの検索・閲覧・送信、予定の一覧・作成・削除を行います。不特定多数への提供や、第三者のデータの収集は行いません。

利用する Google API

  • Gmail API
  • Google Calendar API

データの扱い

取得したデータは、開発者本人の PC 上で処理されます。専用のサーバーは持ちません。詳細はプライバシー ポリシーをご覧ください。
